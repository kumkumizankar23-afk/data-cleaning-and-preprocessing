data-cleaning-and-preprocessing


This project focuses on cleaning and preparing raw data for analysis. The dataset is processed to improve quality and usability.

To clean the dataset by removing errors and making it ready for analysis and visualization.

 Data Cleaning Steps

-Removed duplicate records
-Fixed incorrect data types
-Handled missing data

Tools Used

Pandas
Jupyter Notebook
 
 Output

Cleaned dataset ready for further analysis and visualization.
